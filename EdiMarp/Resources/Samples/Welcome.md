# *edi* · marp

마크다운 한 줄이 곧 슬라이드.
왼쪽에서 쓰고, 오른쪽에서 바로 본다.

---

## 왜 이 에디터인가

- **커서 = 슬라이드.** 커서가 있는 곳의 슬라이드가 항상 보인다
- **미리보기를 클릭**하면 그 줄로 에디터가 점프한다
- 모든 GUI 조작은 마크다운 **텍스트 편집**으로 환원된다
- 그래서 전부 **⌘Z** 로 되돌릴 수 있다

---

## 키보드 하나면 충분

| 단축키 | 동작 |
| --- | --- |
| `⌘ ⏎` | 아래에 새 슬라이드 |
| `⌘ ⇧ D` | 슬라이드 복제 |
| `⌘ ⇧ ↑ / ↓` | 슬라이드 이동 |
| `⌥ ⌘ P` | 발표 시작 |
| `⌥ ⌘ I` | 인스펙터 |
| `⌘ S` | 저장 |
